# مشروع «طلباتي» - خدمة التسوق والطلبات والتوصيل

تطبيق إلكتروني متكامل وشامل لخدمة الشراء بالنيابة عن العملاء وتوصيل الطعام والأدوية والملابس والطلبات المتنوعة عبر واتساب، مع لوحة تحكم إدارية متقدمة وحاسبة تكاليف وأرباح.

---

## 🚀 المميزات الرئيسية

1. **واجهة مستخدم عربية كاملة (RTL):**
   - تصميم بألوان الأخضر والأبيض والكريمي وخط Cairo.
   - 4 أقسام رئيسية مرتبة في شبكة ثنائية (الطعام، الأدوية، الملابس، الطلبات الأخرى).
   - قسم الطعام يحتوي على 10 وجبات مميزة بصور مستقلة لكل وجبة وإمكانية تدوين ملاحظات وتحديد الكميات.
   - قسم الأدوية يقبل الوصفات الطبية بالصورة مع التزام بالسرية والصيدليات المرخصة.
   - قسم الملابس يتيح البحث بالصورة والمقاس واللون والميزانية.
   - قسم الطلبات المتنوعة للبقالة والأغراض المنزلية والهدايا.

2. **سلة مشتريات وتأكيد الطلب عبر واتساب:**
   - جمع المنتجات وحفظها محلياً وفي قاعدة البيانات.
   - توليد رقم طلب مرجعي فريد (مثال: `#TLB-2610-8646`).
   - إعداد رسالة واتساب منسقة وفتح محادثة واتساب الرسمية (رقم: `42481202` / `22242481202`).
   - العملة المعتمدة: **الأوقية**.

3. **لوحة تحكم كاملة للمدير (Full Screen):**
   - محمية بكلمة مرور واسم مستخدم (`admin` / `admin123`).
   - فلترة وبحث وتحديث حالات الطلبات الـ 8 (جديد، قيد المراجعة، بانتظار موافقة السعر، تمت الموافقة، جارٍ الشراء، قيد التوصيل، مكتمل، ملغي).
   - حاسبة التكلفة وصافي الربح لكل طلب بدقة.
   - إضافة وتعديل وحذف وجبات الطعام وتحديث الأسعار والصور.
   - تعديل رقم واتساب والعملة والرسوم.

## 💻 طريقة تشغيل المشروع محلياً (بعد فك ضغط ZIP)

1. تأكد من تثبيت **Node.js** (الإصدار 18 أو أحدث).
2. افتح مجلد المشروع في منفذ الأوامر (Terminal):
   ```bash
   npm install
   ```
3. شغل الخادم في وضع التطوير:
   ```bash
   npm run dev
   ```
4. افتح المتصفح على:
   ```
   http://localhost:3000
   ```

## 📱 طريقة تثبيت التطبيق على هاتف أندرويد (PWA أو APK)

### الخيار الأول: التثبيت المباشر على الهاتف (PWA بدون متجر)
1. افتح رابط موقعك على متصفح Google Chrome في الهاتف.
2. اضغط على قائمة الخيارات (النقاط الثلاث ⁝).
3. اضغط على **«تثبيت التطبيق»** أو **«الإضافة إلى الشاشة الرئيسية»**.
4. سيظهر تطبيق «طلباتي» على شاشة هاتفك كأي تطبيق عادي ويعمل بملء الشاشة بدون شريط متصفح!

### الخيار الثاني: استخراج ملف APK رسمي وجاهز عبر PWABuilder
1. انسخ رابط موقعك المنشور.
2. افتح أداة مايكروسوفت الرسمية: [https://www.pwabuilder.com](https://www.pwabuilder.com)
3. الصق رابط الموقع واضغط **Start**.
4. اختر **Android** ثم اضغط **Package (Generate APK)**.
5. ستحصل فوراً على ملف APK جاهز للتثبيت على الهواتف أو الرفع على متجر Google Play.
